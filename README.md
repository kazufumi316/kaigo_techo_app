# 介護の現場(仮)

## 1. サービス概要

このアプリは、介護現場のスタッフが負担なく、直感的に記録を行うことができるアプリです。

介護現場のスタッフは高齢化しているという問題もあり、パソコンの操作に不慣れな方もいます。そんなパソコン操作が苦手な方達にも問題なく使えるサービスを提供します。

---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

介護の現場に15年以上勤めていたが、ICTの導入を検討する流れの中で「高齢のスタッフ」「パソコン操作が苦手なスタッフ」が使いにくいとのことで、ICT化に至らなかった。

ICTを導入することで新たに覚えることも増え、特に高齢のスタッフは覚えることができないという話の中で、普段から使っているスマートフォンの操作のように直感的な操作で入力できるものであれば使いやすいのではないかと思った。

---

### 2-2. なぜそれが「気になった」のか

パソコン操作が苦手なスタッフに対して、パソコンが操作できるスタッフが代わりに行ったり、手順書を作成することで使えるようになったりはするが、わからない部分はその都度聞くという場面も見られた。

誰もが同じことを同じようにできるようにすることで、業務の負担を減らせるのではないか、誰かが多く仕事を負担しているのではないかを解決できるのではないかと考えた。

---

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと

新たなスタッフが入ってくるたびに、同じ説明を繰り返す必要が出てくる。
形式が変わることで、手順書の作り直しも出てくる。

---

### 3-2. 本当に解決したい課題は何か

- まずは二重での記録をなくすことで、時間の節約を行う
- 直感的に操作できることで、誰もが同じように操作できる
- 誰もが操作できることで、業務負担の軽減につながる

→ 本当に解決したい課題：業務の負担を減らし、利用者への時間の還元に繋げたい
